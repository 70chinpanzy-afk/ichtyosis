# 患者プロフィールの設定方法

LINE に届く「次にできること」を、実際の状況に合わせた内容にするための設定です。
未設定でも配信は動きます（その場合は誰にでも当てはまる汎用の
「患者さんへのポイント」が表示されます）。

## 重要: ファイルに書かないでください

このリポジトリは **公開** されています。病名・使っている薬・通院先などを
ファイルに書いてコミットすると、そのまま誰でも読める状態になります。

プロフィールは **GitHub Actions の Secret** に直接貼ってください。
Secret はリポジトリの管理者にも平文では表示されず、ログにも出ません。

## 手順

1. https://github.com/70chinpanzy-afk/ichtyosis/settings/secrets/actions を開く
2. **New repository secret** を押す
3. Name に `PATIENT_PROFILE` と入力
4. Secret に下のテンプレートを埋めて貼り付ける
5. **Add secret** を押す

次の実行（毎朝7時）から反映されます。

## テンプレート

書ける範囲だけで構いません。空欄の項目は行ごと削っても動きます。
むしろ「困っていること」が具体的なほど、出てくる内容が実用的になります。

以下は書き方の例です。◯の部分を実際の内容に置き換えてください。

```
対象: 子ども（◯歳）
診断名: ◯◯◯
現在の治療: ◯◯（朝晩）／◯◯（入浴後すぐ）／◯◯（症状が強いときだけ）
通院: ◯◯病院 皮膚科・◯か月に1回
特に困っていること: ◯◯のときに悪化する。◯◯が続いている。
気にしていること: ◯◯を続けることについて主治医と相談中。
```

「特に困っていること」は、季節・時間帯・場面まで具体的に書くほど
出てくる内容が実用的になります（例:「いつ」「体のどこが」「どうなるか」）。

## 生成される内容の範囲

安全のため、出力されるのは次の3種類だけに限定しています。

- **聞く** — 次の診察で主治医に確認するとよいこと
- **記録する** — 家庭で観察・記録しておくと診察で役に立つこと
- **準備する** — 申請・問い合わせなど、締切や手続きがあるもの

薬の開始・中止・量の変更をすすめる文や、「効きます」「治ります」といった
断定表現は出力しないようプロンプトで禁止しています。

## 生成物の扱い

プロフィールを当てて作った文は **LINE に送るだけ** で、データベースにも
`frontend/public/data/`（公開されるサイトのデータ）にも保存しません。
サイトに出る「患者さんへのポイント」は、プロフィールを使わない汎用文のままです。
